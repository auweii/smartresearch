# SmartResearch — Documentation

This directory contains the archived assessment deliverables and supporting documentation for the SmartResearch project.

It preserves the project history across Assignments 1–6, including requirements, prototype records, implementation progress, acceptance-criteria snapshots, meeting records, technical diagrams, risk tracking, and final submission materials.
